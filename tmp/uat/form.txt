 Acceptance Form   PROJECT DETAILS©  Project Name:   HartSpec GUI    ___________________________________________________  Project Manager: ©  Mariska Adriaanzen, Ruan Barnard, Anrich Kruger    _______________________________________________  Project Lead:   Mariska Adriaanzen, Ruan Barnard, Anrich Kruger    _________________________________________________          ACCEPTANCE DETAILS  Acceptance ID:             N/A  Requested By:              HartSpec GUI Development Team     ___________________________________________________  Date Requested:           07 October 2026    ______________________________     Description:  The HartSpec GUI is a web-based application situated on the local intranet server of the HartRAO observatory. It provides a web-based interface that integrates the current HartSpec CLC Python pipeline, enabling users to perform the complete maser observation reduction process, from selecting FITS files to atmospheric calibration, spectral fitting, and exporting results. All these activities can be executed without engaging with the terminal. The application can be accessed via a URL on the observatory's internal network. Client-side installation is not required. All calculations are performed on the server, with the graphical user interface communicating through the Streamlit or Plotly Dash callback framework. FITS files are preserved within the observatory's local file system, ensuring thorough data management.  ACCEPTANCE CRITERIA  Criteria 1:  Functional Requirements determined for HartSpec GUI: • A web-based file browser for selecting sources and frequencies (FR-01).  • A FITS file loading and header validation interface (FR-02).  • A file validation interface with quarantine confirmation and persistent audit logs (FR-03).  • A bandpass correction selector with explicit mode toggling and Plotly overlays (FR-04).  • An interactive baseline block editor for selecting velocity ranges (FR-05).  • A six-panel polynomial order comparison visualization with chi-squared scores (FR-06).

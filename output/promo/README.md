# CSIS IT Support promo assets

These assets are ready for an A3 print poster, project proposal, demo, or social post:

- `csis-it-support-a3-poster.png` — 2480 × 3508 A3 portrait poster artwork.
- `csis-it-support-a3-poster.svg` — editable vector source.
- `csis-it-support-60-second-promo.webm` — 60-second caption-led product story with ambient soundtrack.

The source render pages live in `client/public/`:

- `promo-poster.html` — regenerates the A3 PNG from the SVG artwork.
- `promo-video.html` — regenerates the 60-second WebM from the scene sequence.

Start the Vite client and open `/promo-poster.html` or `/promo-video.html` to regenerate either asset.
